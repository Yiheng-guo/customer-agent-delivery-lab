## 验收中修正

1. 带隐藏 `name=id` 的表单会遮蔽 `form.id`，接单、知识和审阅保存分支未执行。改为读取 getAttribute('id')，实际保存与刷新重验通过。
2. 增加服务器发布回归门禁与自动记录，防止仅靠客户端确认跳过回归。
3. 两份即时回归报告曾共享原题期望对象。新增变更期望的兼容性测试暴露问题；现每份报告独立深拷贝，异题/异期望拒绝直接比较。
4. 实际模型 usage 与 provider 必须在引用校验后保留，测试锁定真实返回字段，未知费用仍为 null。
