用途：回答“怎么体验”，让首次访问者照着完成一次工作流。沿用用户此前授权的自主制作方式。

成片采用真实操作页面截图剪辑、中文系统合成配音、步骤字幕。不是连续录屏，也不是模型实时推理演示。页面采集自与公网同版的本地静态构建；企业、知识与工单均为虚构。所有画面只采用明确教学输入，不公开浏览器档案 JSON。

视觉：产品原有墨绿 #203831、主绿 #215b49、纸色 #f7f8f3、米色 #efe8d4；系统中文无衬线，正视机位。以看清操作为优先，省略宣传片的三维运镜、镜头卡、音乐与音效；使用 FFmpeg 而非增加产品运行依赖。截图原始分辨率1280×720，成片1920×1080，不能宣称原生1080p页面采集。页面停留时间由旁白长度加阅读间隔决定。

必须展示：导航入口、输入并发送、来源弹窗、报价转交、接单说明、关闭结果、运行回归、展开失败、知识状态、交付边界、导出入口。

分镜：总览 → 客服页 → 输入试用问题 → 带来源回答 → K02来源 → 企业报价转人工 → 待接单 → 接单说明 → 已关闭及历史 → 运行回归 → 当前报告 → T04原始失败 → 知识列表 → 交付清单及导出 → 体验地址。

数值口径：固定20条合成规则题；旧检索是故意有缺陷的基线，不是竞品或大模型性能。公开体验不调用模型；现金费用不计价。人工工单没有连接外部客服。
