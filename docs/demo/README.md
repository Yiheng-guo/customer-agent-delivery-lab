[MP4 视频](../../public/demo/walkthrough.mp4) · [完整文案与时间线](source/timeline.json) · [制作口径](source/brief.md)

3分48秒，H.264 / AAC，1920×1080、24fps，中文系统合成配音。真实操作截图剪辑，不是连续录屏；页面截图原始1280×720。公开版演示来源规则和本地角色模拟，没有真实模型调用或企业客服连接。

操作：客服提问 → 点击来源 → 企业报价转交 → 模拟接单与关闭 → 实际运行20题规则回归 → 展开失败原文 → 检查知识排除状态 → 查看交付边界 → 导出当前浏览器档案。

## 验证记录

- CUA实际操作保存问题、来源、工单状态、回归报告、知识和交付页面。
- 初版输入截图混入无关文字；独立审查发现后重采。初版字幕31px，修订为56px并换行。
- 补拍K09失效、K10权限排除、K11待审核及上线未验收条目；收尾使用20/20的总览。
- 独立审查完整解码5472帧，无解码错误；228.02秒，音量均值−19.0dB、峰值−1.9dB，无削波。
- 浏览器在支持Range的本地预览中验证视频解码、播放和149秒章节跳转；普通Python静态预览不支持Range，已记录限制。
- `npm test` 20项通过，`npm run check`及公开构建通过。

仍有边界：关闭工单段采用已关闭结果画面，省略填写关闭表单；T04展示业务答案和失败原因，引用JSON仅局部入镜。部分画面保留完成提示。未进行真人配音发音审阅，VTT按句长度分配时间，非逐字校时；手机看业务正文建议全屏或暂停。

## 重新生成

`source/render.py` 只读取已经由CUA采集的截图，使用Pillow、FFmpeg与macOS `say`渲染；不执行浏览器控制，不增加应用运行依赖。指定本机FFmpeg路径即可重渲。中间音频与片段在`rendered/`，不提交Git。

制作参考：[video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)，采用真实页面、产品配色、逐帧验证与独立终检方法。教学片没有使用其音乐、模板或镜头卡。
